## metric.rcx_missing_corner_count

**Meaning:** `rcx_missing_corner_count` is the normalized RCX metric shown by ECOS when its source fact is available.

**Calculation:** ECC derives SPEF file and expected-corner coverage, parses electrical totals by corner, and publishes missing-corner, parse-failure, worst-capacitance, and worst-resistance facts. Missing source data remains unavailable; it is not converted to zero or a success claim.

**Source evidence:** **ecc.runner**, **ecc.module**, **ecc.metrics**, **gui.step_metrics**
