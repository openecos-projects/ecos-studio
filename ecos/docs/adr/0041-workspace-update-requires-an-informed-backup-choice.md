# Workspace Update requires an informed backup choice

A structural Workspace Update does not assume either backup or deletion. Before execution, ECOS Studio explains that Flow state, engineering results, Artifacts, logs and user files will be replaced, then requires the user to choose explicitly between retaining the original as a Project-managed Workspace Replacement Backup or permanently deleting it; cancellation leaves the Workspace unchanged, and an Agent cannot make this choice for the user.
